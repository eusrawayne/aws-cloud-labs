# Prompts de Imagens Mnemônicas (AWS)

Cole qualquer prompt abaixo no seu gerador de imagens preferido.

## Estilo base obrigatório (já embutido em todos os prompts)
- infográfico moderno
- flat premium / semi-isométrico
- fundo claro
- pouco texto (máx. 2 labels curtas)
- ícones grandes
- metáfora memorável
- sem logos oficiais
- sem branding oficial AWS

> Dica: mantenha proporção 4:5 para cards mobile e 16:9 para hero/desktop.
