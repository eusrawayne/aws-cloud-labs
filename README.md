# AWS Cloud Labs 🚀

> Hands-on AWS labs designed to reinforce concepts from the AWS Cloud Practitioner certification and real-world beginner projects.

## 📌 Overview

This repository contains practical labs exploring core AWS services, cloud concepts, and best practices. Each lab is designed to be self-contained, include infrastructure diagrams, and connect to AWS Cloud Practitioner exam topics.

## 🎯 Labs

### Lab 1: S3 Static Website Hosting
- **Objective**: Host a static website on Amazon S3 with proper security configurations
- **Services**: S3, CloudFront, Route 53
- **Key Concepts**: Bucket policies, public access blocking, CDN distribution
- **Status**: Coming soon

### Lab 2: EC2 Basic Server Setup
- **Objective**: Launch and secure an EC2 instance with monitoring
- **Services**: EC2, Security Groups, CloudWatch
- **Key Concepts**: Instance types, security groups, monitoring metrics
- **Status**: Coming soon

### Lab 3: IAM Least Privilege Access
- **Objective**: Create IAM policies following least privilege principle
- **Services**: IAM, Roles, Policies
- **Key Concepts**: Access control, policy design, role-based access
- **Status**: Coming soon

### Lab 4: VPC & Networking Basics
- **Objective**: Set up a VPC with subnets, gateways, and routing
- **Services**: VPC, Subnets, Gateways, Route Tables
- **Key Concepts**: Network segmentation, routing, NAT
- **Status**: Coming soon

### Lab 5: Lambda Serverless Function
- **Objective**: Create and deploy a serverless function with API Gateway
- **Services**: Lambda, API Gateway, CloudWatch Logs
- **Key Concepts**: Serverless computing, event-driven architecture, monitoring
- **Status**: Coming soon

## 🛠️ Prerequisites

- AWS free tier account or active AWS account
- AWS CLI installed and configured
- Basic understanding of cloud concepts
- Terminal/command line familiarity

## 🚀 Getting Started

1. Clone this repository: `git clone https://github.com/eusrawayne/aws-cloud-labs.git`
2. Navigate to a lab folder
3. Follow the lab README and steps
4. Clean up resources after completing each lab to avoid charges

## 💡 Learning Goals

By completing these labs, you will:
- Understand core AWS services and their use cases
- Gain hands-on experience with cloud architecture
- Learn security best practices in AWS
- Prepare for AWS Cloud Practitioner certification
- Build a portfolio project for your GitHub
